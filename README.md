# برنامه یاسر — Android Offline v2

اپ شخصی و کاملاً آفلاین با دو بخش اصلی: «خرید هفتگی» و «لیست کارها».

## خرید هفتگی

- آرشیو دائمی هفته‌های هر سال شمسی، از شنبه تا جمعه
- رفتن به سال قبل و بعد و باز کردن هر هفته به‌صورت مستقل
- بودجه پیش‌فرض هر هفته: ۵٬۰۰۰٬۰۰۰ تومان
- امکان تغییر بودجه فقط برای همان هفته و بازگرداندن آن به ۵ میلیون
- افزودن، ویرایش نام و حذف ردیف‌های خرید
- ثبت/ویرایش/پاک‌کردن قیمت هر ردیف
- محاسبه خودکار خرج‌شده و مانده بودجه
- تیک خرید انجام‌شده؛ ثبت قیمت، ردیف را خودکار خریداری‌شده علامت می‌زند
- تمام اطلاعات روی گوشی ذخیره می‌شوند و هفته‌های گذشته پاک نمی‌شوند

## لیست کارها

- ذخیره آفلاین کارها
- دسته‌بندی: امروز، مغازه، خونه، ققنوس، شخصی
- آلارم دقیق محلی Android بدون اینترنت
- بازیابی آلارم‌ها بعد از روشن شدن گوشی
- تکرار روزانه، هفتگی و ماهانه
- امضای ثابت APK برای اینکه نسخه‌های بعدی روی همین نسخه نصب شوند و اطلاعات باقی بمانند

## ساخت APK با GitHub Actions

تمام **محتویات** این پوشه را در ریشه مخزن `Shopping-list` قرار بده؛ `settings.gradle` و پوشه `app` باید مستقیم در صفحه اول مخزن باشند و `.github/workflows/build-apk.yml` هم باید وجود داشته باشد.

بعد از Commit، Workflow با نام **Build Android APK** خودکار اجرا می‌شود. بعد از سبز شدن Run، از بخش **Artifacts** فایل `Yaser-Tasks-APK` را دانلود کن. داخل آن `app-debug.apk` است.

نسخه: 2.0.0

> نسخه 2 اولین نسخه با امضای ثابت پروژه است. اگر نسخه آزمایشی v1 روی گوشی نصب است و Android اجازه نصب v2 روی آن نداد، فقط همین یک‌بار v1 را حذف و v2 را نصب کن. از v2 به بعد APKهای جدید می‌توانند روی نسخه قبلی نصب شوند.
