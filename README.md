# کارهای یاسر — Android Offline

اپ شخصی آفلاین برای کارها، یادآورها و خرج خانه.

## امکانات

- ذخیره اطلاعات فقط روی خود گوشی با SharedPreferences/JSON
- دسته‌ها: امروز، مغازه، خونه، ققنوس، شخصی
- آلارم دقیق محلی Android بدون اینترنت
- صدای آلارم حتی وقتی برنامه بسته است
- بازیابی آلارم‌ها بعد از روشن شدن دوباره گوشی
- تکرار روزانه، هفتگی و ماهانه
- ثبت خرج خانه و بودجه هفتگی ۵,۰۰۰,۰۰۰ تومان
- بدون Supabase، سرور، حساب کاربری یا Push اینترنتی

## ساخت APK با GitHub Actions

تمام محتویات این پوشه باید در ریشه مخزن `Shopping-list` قرار بگیرد؛ یعنی `settings.gradle` باید مستقیم در صفحه اول مخزن دیده شود و پوشه دیگری دور پروژه نباشد.

بعد از Commit، به تب **Actions** برو. Workflow با نام **Build Android APK** اجرا می‌شود. پس از سبز شدن Build، وارد همان Run شو و پایین صفحه از بخش **Artifacts** فایل `Yaser-Tasks-APK` را دانلود کن. داخل آن `app-debug.apk` است.

## نصب روی گوشی

APK را به گوشی منتقل و نصب کن. Android ممکن است بار اول برای نصب از مرورگر/Files اجازه `Install unknown apps` بخواهد. هنگام اولین اجرای برنامه، اجازه Notifications را بده تا آلارم اعلان هم نشان دهد.

این نسخه برای استفاده شخصی و sideload ساخته شده است.
